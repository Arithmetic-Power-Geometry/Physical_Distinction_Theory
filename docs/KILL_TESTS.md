3. Persistent violation of `c'=c chi` inside the declared controlled-dephasing model falsifies the model assumptions.
4. Failure of the total-tensor product-rule identity is an algebraic inconsistency.
5. A PDT coherence prediction that uses target coherence to infer `Gamma_A` is disqualified from zero-parameter evidence.
