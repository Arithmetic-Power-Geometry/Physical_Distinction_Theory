# PDT theorem-status map

The repository follows the manuscript's status discipline.

- **PDT no-go:** scalar capacity does not determine geometry.
- **PDT no-go:** CEU+CER do not force BQDC / Euclidean geometry.
- **Conditional PDT theorem:** CEU+CER+RDE, with finite dimensionality, closed reversible group and maximal-pair coverage, yield an ellipsoid / Euclidean ball `B^n`.
- **PDT no-go / local dimension-selection:** for every `n>=2`, the Euclidean ball `B^n` satisfies the current local CEU/CER/RDE structure; therefore those local assumptions alone cannot select `n=3`.
- **Imported/known metric-entropy result + PDT operational corollary:** for a Euclidean `B^n`, resolution-scaled distinction capacity obeys `K_R(epsilon)=n log2(1/epsilon)+O(1)`, so the asymptotic capacity slope identifies an already-existing metric dimension `n`; this does **not** select `n=3`.
- **CONDITIONAL / IMPORTED-KNOWN dimension filter:** if an elementary Euclidean distinction space additionally carries a nontrivial bilinear antisymmetric normed vector product that is orthogonal to its inputs and satisfies the Jacobi identity, known cross-product classification leaves only `n=3`: nontrivial normed products occur in `n=3,7`, and the standard 7D octonionic product fails Jacobi. This identifies a precise sufficient interaction axiom but is **not** a PDT-native derivation until that axiom is physically justified without importing 3D quantum/rotation structure.
- **CONDITIONAL GDSD dimension filter / representation mathematics IMPORTED-KNOWN:** if an elementary Euclidean distinction space `V=R^n` with full connected reversible isotropy `SO(n)` obeys Generator–Distinction Self-Duality—an equivariant one-to-one identification `V -> so(V)` between primitive distinction directions and primitive infinitesimal reversible generators—then `n=dim so(n)=n(n-1)/2`, whose only positive-dimensional solution is `n=3`. The 3D converse is supplied by the standard Hodge/axial-vector identification. This uses a weaker algebraic assumption than the normed-cross-product route, but GDSD is still an unproved PDT physical axiom and the representation theorem is established mathematics; therefore it is **not** a breakthrough.
- **CONDITIONAL GE+NCR dimension filter / Lie mathematics IMPORTED-KNOWN:** a still weaker route replaces exact GDSD by (GE) Generator Economy, `dim so(n) <= n`, and (NCR) genuinely noncommuting connected reversible dynamics. Under full isotropy `SO(n)`, GE gives positive `n<=3`, while `so(1)` is trivial, `so(2)` is abelian, and `so(n)` is non-abelian for `n>=3`, so NCR gives `n>=3`. Hence GE+NCR isolates `n=3`. The code audits `n=1..12` and the test suite scans through `n=1000`. The mathematics is standard and GE/NCR are not yet derived from PDT resource/composition axioms, so this remains **CONDITIONAL, not a breakthrough**.
- **CONDITIONAL OSC+NCR dimension theorem / PDT-native operational axiom candidate, mathematics IMPORTED-KNOWN:** Operational Self-Calibration (OSC) requires the small-resolution covering-number exponent of the connected reversible control group not to exceed the distinction-capacity exponent of the elementary state body. For `B^n` with full connected isotropy `SO(n)`, standard metric entropy gives exponents `n` and `n(n-1)/2`; OSC therefore yields `n<=3`, while genuinely noncommuting reversibility excludes `n=1,2`, leaving exactly `n=3`. This operationalizes Generator Economy in PDT's resource/distinction language and is audited for `n=1..12` with tests through `n=1000`, but OSC is not yet independently derived or experimentally established, so this is **not a breakthrough claim**.
- **DECISIVE FALSIFICATION of an OSC derivation route / IMPORTED-KNOWN no-programming prior art:** exact deterministic self-programmability cannot justify OSC. The Nielsen–Chuang no-programming theorem rules out a finite-dimensional elementary program system exactly encoding a continuous family of distinct unitaries. Therefore the only viable OSC route is finite-resolution calibration/encoding (or another resource inequality), which must itself be independently derived or tested. Approximate programming and program-dimension bounds are established prior art, so any future PDT calibration-capacity theorem must be separated from those results.
- **CONDITIONAL PCC+NCR dimension theorem / PDT-native pairwise-calibration axiom candidate, group-base mathematics IMPORTED-KNOWN:** Pairwise Calibration Closure (PCC) requires one ordered pair of elementary reference states to form a base for the full connected reversible `SO(n)` action. Two independent references have pointwise stabilizer `SO(n-2)`, so PCC holds only for `n<=3`; genuinely noncommuting connected reversibility excludes `n=1,2`, leaving exactly `n=3`. More generally the natural `SO(n)` action requires `n-1` independent reference vectors to determine a control. The branch includes explicit nonidentity stabilizer witnesses for every `n=4..12` and tests the exact dimension filter through `n=100`. PCC is a concrete, falsifiable PDT-native axiom candidate because it ties control calibration to one primitive distinction pair, but it is not yet independently derived or experimentally established and the base-size mathematics is known, so this is **not yet a breakthrough**.
- **DECISIVE FALSIFICATION of over-broad PCC / alternative reversible-group counterexamples:** PCC plus noncommuting connected reversibility does **not** select `n=3` without full `SO(n)` isotropy. For the natural action of `SU(m)` on `C^m ~= R^(2m)`, the pointwise stabilizer of `r` complex-independent references is `SU(m-r)`, so the minimal reference count is `m-1`. Consequently `SU(2)` on real dimension `4` and `SU(3)` on real dimension `6` are explicit higher-dimensional noncommuting PCC counterexamples. Full isotropy (or a deeper principle that excludes these subgroups) is therefore essential.
- **CONDITIONAL TPI+PCC+NCR dimension filter / sphere-action classification IMPORTED-KNOWN:** full `SO(n)` isotropy can be weakened to Two-Point Isotropy (TPI): after fixing one pure distinction, its reversible stabilizer is transitive on all directions at the same angle, operationally meaning no preferred azimuth around a fixed distinction. In the orthogonal family the ordered-pair stabilizer is `SO(n-2)`, so PCC permits only `n<=3`, and NCR excludes `n=2`. The exceptional TPI sphere actions `G2` on `R^7` and `Spin(7)` on `R^8` fail PCC because their ordered-pair stabilizers are `SU(2)` and `SU(3)` respectively. Thus the audited TPI+PCC+NCR conjunction leaves only `n=3`. The classification/stabilizer mathematics is known and TPI/PCC remain underived PDT axioms, so this is **CONDITIONAL, not a breakthrough**.
- **SHARPENED SYMMETRY BOUNDARY:** ordinary transitivity/homogeneity is insufficient for dimension selection; proper connected transitive subgroups such as `SU(2)` and `SU(3)` survive PCC in real dimensions 4 and 6. The currently surviving symmetry requirement is therefore strictly stronger than sphere transitivity but weaker than assuming the full orthogonal group. A PDT-native derivation of TPI (or a still weaker sufficient substitute) is now the key unresolved symmetry step.
- **PROVED orbit-completeness equivalence / DECISIVE CIRCULARITY BOUNDARY / IMPORTED-KNOWN group-action mathematics:** fix a reference distinction `x`, write `H=G_x`, and let `s_x` be the declared scalar distinction around `x`. Because `H` preserves `s_x`, saying that `s_x` is a complete invariant of `H`-orbits is equivalent to saying that `H` is transitive on every `s_x` level set—i.e. TPI relative to that scalar. Thus "operational completeness of the current scalar" cannot independently derive TPI; it assumes TPI in equivalent orbit-separation language. The `SU(m)` family gives explicit failures in real dimensions 4,6,8,10,12: equal Euclidean scalar distance/angle can hide a different complex inner-product invariant preserved by the stabilizer. A non-circular dimension derivation must therefore force collapse of all stabilizer-invariant operational information to the PDT scalar from independent composition/resource/calibration primitives, rather than declaring completeness.
