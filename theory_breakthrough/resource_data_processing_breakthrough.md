# PDT Resource Data-Processing Breakthrough Attack

**Status:** canonical theorem-development record for the next PDT quantum-reconstruction step.

## Executive result

A naive claim that a Bregman regret derived from an optimal decision value is automatically monotone under all physical channels is false in general. The correct route is more precise:

1. A resource-bounded operational distinguishability functional obtained by optimizing affine decision payoffs is automatically contractive under admissible channels by pullback/closure of admissible actions.
2. The corresponding channel contraction is exact and elementary; it does not require Hilbert geometry.
3. A generic Bregman regret generated by the optimal value function does **not** inherit this data-processing inequality merely from contraction of the value function.
4. Therefore Harremoës' rank-two ball theorem cannot be invoked from resource monotonicity alone unless PDT adds or derives an additional **sufficiency/recovery condition** for the regret.
5. The clean PDT bridge is: resource processing defines a canonical operational distinguishability contraction; reversible recoverability defines sufficiency; if the chosen convex regret is invariant under sufficient channels (and, in the stronger version, monotone under all affine physical channels), then rank-two results yield spectrality/ball geometry.

This file records the exact proofs and the resulting corrected breakthrough chain.

## 1. Resource-bounded decision structure

Let `R` denote a complete resource profile, including allowed interventions, energy, time, accessible region, and admissible error.

For a state `omega`, let `A_R` be the set of admissible decision procedures. For each `a in A_R`, let

`u_R(a, omega)`

be the expected distinction payoff. Operational mixing makes `u_R(a, .)` affine.

Define the optimal decision value

`F_R(omega) = sup_{a in A_R} u_R(a, omega)`.

As a supremum of affine functions, `F_R` is convex.

---

## 2. Exact resource data-processing theorem for operational distinguishability

Define the symmetric resource-bounded operational distinguishability

`Delta_R(omega, sigma) = sup_{a in A_R} |u_R(a, omega) - u_R(a, sigma)|`.

Assume **admissible pullback closure**:

For every allowed physical channel `Phi : Omega_R -> Omega_R'` and every post-channel procedure `b in A_R'`, the composite procedure `b o Phi` is an admissible pre-channel procedure in `A_R`, with payoff preservation

`u_R(b o Phi, omega) = u_R'(b, Phi(omega))`.

Then

`Delta_R'(Phi omega, Phi sigma)
 = sup_{b in A_R'} |u_R'(b,Phi omega)-u_R'(b,Phi sigma)|
 = sup_{b in A_R'} |u_R(b o Phi,omega)-u_R(b o Phi,sigma)|
 <= sup_{a in A_R} |u_R(a,omega)-u_R(a,sigma)|
 = Delta_R(omega,sigma).`

Hence

**Theorem (PDT Resource Data Processing).**

`Delta_R'(Phi omega, Phi sigma) <= Delta_R(omega,sigma)`.

This is an exact theorem derived directly from the operational resource model. It formalizes the principle that physical processing cannot create freely accessible distinction when every post-processing strategy can be simulated as a pre-processing strategy followed by the same channel.

If `Phi` has an admissible recovery channel `Psi` satisfying

`Psi Phi omega = omega`, `Psi Phi sigma = sigma`,

then applying the inequality to `Phi` and then to `Psi` gives equality:

`Delta_R'(Phi omega,Phi sigma) = Delta_R(omega,sigma)`.

Thus **recoverability implies sufficiency equality** for the operational distinction functional.

## 3. Why generic optimal-value Bregman regret is NOT automatically monotone

Suppose a unique optimizer at `sigma` exists, denoted `a_sigma`, and define regret

`D_R(omega || sigma) = F_R(omega) - u_R(a_sigma, omega)`.

When `F_R` is differentiable and `u_R(a_sigma, .)` is its supporting affine functional at `sigma`, this is the Bregman divergence generated by `F_R`.

However, from

`F_R'(Phi omega) <= F_R(omega)`

one cannot conclude

`D_R'(Phi omega || Phi sigma) <= D_R(omega || sigma)`.

The reason is that both the optimal value term and the reference-action payoff change under the channel, and their difference is not ordered by the individual value contraction. Therefore **generic decision regret does not inherit data processing for free**.

This blocks an invalid shortcut that would otherwise overclaim the Harremoës rank-two theorem.

## 4. Correct sufficiency bridge

A channel `Phi` is **sufficient** for a pair `(omega,sigma)` if an admissible recovery `Psi` exists with

`Psi Phi omega = omega`, `Psi Phi sigma = sigma`.

PDT can impose or derive the following physically interpretable condition on a selected regret `D`:

**Distinction-Sufficiency Invariance**

`D(Phi omega || Phi sigma) = D(omega || sigma)`

for every channel that is sufficient for the pair.

This expresses that a physically reversible/recoverable compression has discarded no distinction relevant to the pair.

Harremoës' rank-two results then become applicable only after their technical hypotheses are checked: a convex body of rank two with a Bregman divergence satisfying sufficiency is spectral; with monotonicity under the required class of affine channels, the body is a ball/spin factor.

## 5. Stronger route if monotone Bregman regret is physically justified

If PDT identifies a differentiable strictly convex potential `F` whose Bregman divergence

`D_F(omega||sigma) = F(omega)-F(sigma)-<grad F(sigma),omega-sigma>`

`D_F(Phi omega||Phi sigma) <= D_F(omega||sigma)`

`rank 2 + monotone Bregman divergence => Euclidean ball/spin factor`.

Consequently

Therefore

so BQDC is downstream rather than primitive.
