# PDT Next Attack — Proper Scoring, Sufficiency, and the Remaining Quantum Bridge

## Purpose

This note records the next theorem attack after the exact resource data-processing theorem. It is deliberately adversarial: every implication is classified as proved, imported, conditional, or false.

## 1. Canonical binary discrimination value is not enough

For equal priors, define the resource-bounded binary success advantage

`A_R(omega,sigma) = sup_{e in E_R} |e(omega)-e(sigma)|`.

This is a support-function/seminorm-type operational quantity. Under admissible channel pullback it satisfies exact data processing.

However, support functions are generally piecewise linear and need not generate a differentiable strictly convex potential. Therefore the canonical Helstrom-style discrimination value does not automatically produce a Bregman divergence suitable for the rank-two Harremoës rigidity theorem.

**Conclusion:** the direct path

`Helstrom advantage -> Bregman regret -> ball`

is not valid without additional structure.

## 2. Proper-score construction

A proper scoring rule on a convex state space is a family of affine payoffs `s(q,omega)` indexed by reported states `q`, such that truthful report maximizes expected score:

`s(omega,omega) >= s(q,omega)` for all `q`.

Define

`F(omega)=s(omega,omega)`

and regret

`D_F(omega||q)=F(omega)-s(q,omega)`.

When `F` is differentiable and the score is generated by its supporting hyperplanes,

`D_F(omega||q)=F(omega)-F(q)-<grad F(q),omega-q>`,

which is a Bregman divergence.

Thus a canonical PDT route would require a physically selected **strictly proper distinction score**, not merely a binary test advantage.

## 3. Exact sufficiency theorem that PDT can demand physically

Let `Phi` be sufficient for a pair `(omega,sigma)`, with admissible recovery `Psi` such that

`Psi Phi omega=omega`, `Psi Phi sigma=sigma`.

For any divergence already known to obey data processing under both `Phi` and `Psi`, equality follows:

`D(Phi omega||Phi sigma) <= D(omega||sigma)`

and

`D(omega||sigma)=D(Psi Phi omega||Psi Phi sigma) <= D(Phi omega||Phi sigma)`.

Therefore

`D(Phi omega||Phi sigma)=D(omega||sigma)`.

So **monotonicity implies sufficiency invariance** by a two-line recovery argument.

The hard direction remains deriving monotonicity of a Bregman regret from PDT physical primitives.

## 4. Candidate PDT axiom reduced to an operational uniqueness statement

The least reconstruction-like remaining principle is:

**Canonical Distinction Score (CDS).** For each irreducible elementary resource sector there exists, up to positive scale and affine gauge, a unique smooth strictly proper score whose regret is invariant under reversible transformations and cannot increase under admissible coarse-graining.

If CDS is independently motivated or derived, then its regret is a monotone Bregman divergence. In rank two, Harremoës' theorem forces ball/spin-factor geometry.

This produces

`rank 2 + CDS => B^n => BQDC`.

But CDS is still a postulate until uniqueness/existence is derived from the resource theory.

## 5. Stronger potential derivation route: operational composition of scores

A possible derivation target is to demand four properties of the elementary distinction score:

1. **Strict propriety:** truthful state report uniquely maximizes expected distinction score.
2. **Reversible covariance:** reversible relabelings leave regret invariant.
3. **Independent additivity:** for independent systems, total regret is additive.
4. **Recovery invariance:** sufficient/recoverable processing preserves regret.

In classical probability, closely related locality/sufficiency/additivity conditions are known to select information divergence/logarithmic score under appropriate regularity assumptions. The research task is to determine whether the PDT rank-two operational state space plus these physical conditions already forces the needed smooth monotone regret before assuming quantum geometry.

## 6. Breakthrough criterion

A genuinely stronger PDT result would be one of:

- prove CDS from the resource-bounded discrimination model;
- prove that any smooth strictly proper reversible-covariant additive distinction score is automatically monotone under admissible channels;
- or derive binary spectral/radial resolution directly from the operational contraction `Delta_R` plus a noncircular completeness principle.

Until one of these is achieved, the quantum reconstruction is strong but remains conditional at this bridge.

## 7. Current rigorous theorem stack

**Proved inside PDT:**

`admissible pullback closure => Delta_R(Phi omega,Phi sigma) <= Delta_R(omega,sigma)`.

`exact recovery => equality for Delta_R`.

`binary resolution + common unbiased erasure + continuous pure-state transitivity => Euclidean ball => BQDC`.

**Established external theorem:**

`rank-two monotone Bregman divergence => ball/spin factor`.

`Euclidean ball + locally tomographic continuous interacting composites => B^3` under the Masanes et al. hypotheses.

`Jordan systems + local tomography + a qubit => complex finite-dimensional quantum theory` under Barnum-Wilce/Hanche-Olsen-type assumptions.

**Not proved:**

`K_epsilon=1 bit => spectrality`.

`Delta_R contraction => Bregman-regret contraction`.

`resource boundedness alone => complex quantum theory`.

This status firewall must be retained in every manuscript revision.
