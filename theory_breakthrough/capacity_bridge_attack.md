# Attack on the Global-Capacity -> Local-Geometry Bridge

## Executive result

A scalar statement such as

`K_epsilon(Omega;R)=1 bit`

cannot by itself determine the local convex geometry. The correct strategy is therefore **not** to try to extract BQDC directly from the integer-valued code capacity. Instead PDT needs a richer resource-bounded distinction functional whose *full state dependence* satisfies operational sufficiency/data processing.

This note proves the no-go and gives the strongest rigorous bridge currently available.

---

## No-go theorem — one-bit maximal code capacity does not determine Euclidean geometry

### Statement
There exist infinitely many finite-dimensional compact convex state spaces with maximal perfectly distinguishable codebook size two but with mutually inequivalent local norm geometries. Consequently the scalar condition `K=log_2 2=1` cannot imply BQDC, an inner product, or a unique state space.

### Construction
Consider, for fixed dimension `d>=2`, the centrally symmetric strictly convex bodies

`B_p^d = {x in R^d : ||x||_p <= 1}`,  `1<p<infinity`.

Use the standard GPT construction with normalized affine effects from the full dual effect cone.

1. Antipodal boundary points can be perfectly distinguished by a supporting affine functional, so the capacity is at least two.
2. A strictly convex compact body has no nontrivial proper exposed face: a supporting hyperplane intersects the body in at most one boundary point.
3. If three states `alpha_1,alpha_2,alpha_3` were perfectly distinguishable, there would be an effect `e_1` with `e_1(alpha_1)=1` and `e_1(alpha_2)=e_1(alpha_3)=0`. The zero-level exposed face of `e_1` would therefore contain two distinct boundary states, contradicting strict convexity.
4. Hence the maximal perfectly distinguishable set has size exactly two.

Therefore every `B_p^d` has one-bit maximal capacity in this operational sense.

But for `p != 2`, the norm fails the parallelogram law. For example in `R^2`, with `x=(1,0)` and `y=(0,1)`,

`||x+y||_p^2 + ||x-y||_p^2 = 2 * (2^(1/p))^2 = 2^(1+2/p)`,

whereas

`2||x||_p^2+2||y||_p^2=4`.

Equality requires

`2^(1+2/p)=4`, hence `p=2`.

Thus

`one-bit capacity !=> BQDC`.

This is a decisive structural no-go: the global codebook cardinality is too coarse to encode local quadratic geometry.

## Consequence for PDT

Do **not** try to identify the raw integer/log-cardinality capacity `K_epsilon` with the local quadratic distinction power `Q_D`.

Keep two objects:

- `K_epsilon`: global finite-resource code capacity;
- `Q_D`: local state-dependent distinction power / metric quantity.

The research task is to derive `Q_D` from a *state-resolved operational value functional* associated with `K_epsilon`, not from the single number `K_epsilon` itself.

---

## Construct a state-resolved resource-bounded distinction value

Let `A_R` be the set of admissible discrimination/decision procedures at resource budget `R`. Let `u(a,omega)` be the expected operational distinction payoff of procedure `a` on state `omega`, affine in `omega` for each fixed `a`.

Define the optimal value

`F_R(omega) = sup_{a in A_R} u(a,omega)`.

Because it is a supremum of affine functions, `F_R` is convex.

When `F_R` is differentiable, define the regret for using the optimizer appropriate to `sigma` when the true state is `omega`:

`D_R(omega||sigma) = F_R(omega)-F_R(sigma)-<grad F_R(sigma), omega-sigma>`.

This is the Bregman divergence generated by `F_R` and is nonnegative by convexity.

### PDT interpretation
`D_R(omega||sigma)` is the resource-bounded loss in attainable distinction performance caused by treating `omega` as though it were `sigma`.

Unlike `K_epsilon`, it depends on the actual states and can carry local geometric information.

---

## Lemma — reversible invariance of the value induces reversible invariance of regret

If the admissible decision family is covariant under reversible transformations and the resource budget is preserved, then

`F_R(g omega)=F_R(omega)`

and consequently

`D_R(g omega || g sigma)=D_R(omega||sigma)`.

This follows by bijectively relabeling admissible procedures under `g`.

---

## Principle RS — Resource Sufficiency

For a physical channel `Phi` that is sufficient for the pair `{omega,sigma}` at budget `R` (there exists an admissible recovery `Psi` with `Psi Phi omega=omega` and `Psi Phi sigma=sigma`), the distinction regret is invariant:

`D_R(Phi omega || Phi sigma)=D_R(omega||sigma)`.

This is a natural resource-bounded form of the statistical sufficiency principle: reversible lossless compression of all distinction-relevant information must not change distinction regret.

---

## Principle RDP — Resource Data Processing

For every admissible channel `Phi`,

`D_R(Phi omega || Phi sigma) <= D_R(omega||sigma)`

after accounting for the transformed resource budget.

This says physical processing cannot increase state distinguishability/regret for free.

## Imported theorem — rank-two sufficiency/monotonicity rigidity

Harremoës, *Entropy on Spin Factors*, arXiv:1707.03222, proves for rank-two convex bodies that:

1. a Bregman divergence satisfying sufficiency forces spectrality;
2. a monotone Bregman divergence forces the convex body to be a ball (spin factor).

Therefore, if PDT establishes that its operational regret `D_R` is a well-defined Bregman divergence satisfying RS (and especially RDP), then for an elementary one-bit/rank-two state space:

`rank 2 + RS => spectrality`,

and

`rank 2 + RDP => Euclidean ball/spin factor`.

This yields a powerful bridge:

`resource-bounded distinction decision theory`

`=> Bregman regret + sufficiency/data processing`

`=> spectrality / ball geometry`

`=> BQDC`.

The Harremoës implications are imported literature, not new PDT theorems. The PDT novelty target is deriving the exact operational regret and RS/RDP from the original resource primitive.

## Strongest currently defensible bridge theorem

### Theorem (conditional PDT capacity-to-ball bridge)
Let `Omega` be a finite-dimensional elementary state space of maximal distinction capacity one bit. Suppose:

1. the resource-bounded distinction decision problem has a differentiable convex optimal-value function `F_R`;
2. its regret is the associated Bregman divergence `D_R`;
3. `D_R` obeys physical data processing under all admissible channels.

Then the rank-two result of Harremoës implies that `Omega` is a Euclidean ball/spin factor. Consequently an invariant quadratic distinction form exists and BQDC holds.

### Proof
- one-bit elementary capacity gives operational rank two;
- assumptions 1-2 construct a Bregman divergence;
- assumption 3 provides monotonicity;
- invoke the rank-two monotonicity theorem to obtain ball geometry;
- a Euclidean ball has an inner-product norm and therefore satisfies the parallelogram identity. QED.

---

## Why this is stronger than CER+CEU as postulates

The earlier radial proof uses Complete Elementary Resolution (CER) and Complete-Erasure Uniqueness (CEU) directly. The information-geometric route replaces those geometric-looking assumptions by a single decision-theoretic requirement:

`resource-bounded distinction regret obeys data processing`.

This is closer to the original PDT primitive and gives an independent proof route.

## Immediate falsification tests

Any candidate PDT distinction divergence must be rejected if one of the following occurs:

1. it increases under a free/admissible coarse-graining;
2. a reversible sufficient transformation changes it;
3. it is not nonnegative;
4. it depends on arbitrary state labels rather than operational statistics;
5. it yields a rank-two non-ball state space while satisfying the claimed monotonicity assumptions (which would contradict the imported theorem, signalling a hidden assumption mismatch);
6. it silently identifies integer code capacity with local quadratic norm.

Derive an explicit `F_R` from the existing PDT finite-resource discrimination model (Helstrom error / admissible interventions / codebook optimization), and prove rather than assume:

`D_R(Phi omega||Phi sigma) <= D_R(omega||sigma)`.

`physical distinction resources -> monotone regret -> B^n -> BQDC`
