# Cycle 372 — Metric orientation no-go

Result: any handedness functional that depends only on a tuple's Gram matrix cannot distinguish that tuple from its reflected copy. For orthogonal Q, G(QX)=X^T Q^T Q X=G(X). Thus metric-only distinction data cannot derive physical handedness in any dimension.
