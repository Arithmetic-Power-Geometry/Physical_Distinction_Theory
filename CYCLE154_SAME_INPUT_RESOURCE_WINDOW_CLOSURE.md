# PDT-II Cycle 154 — Same-input resource-window closure

## Target
Attack target (3): seek a same-input quantitative prediction with P_PDT(O|I,R) != P_QM(O|I,R) under identical microscopic inputs and the same declared resource window.

## Closure theorem
Let rho be the microscopic state, Lambda_R the physical channel induced by resource window R, and E_O the effect for outcome O. If both PDT and QM use the same triple (rho, Lambda_R, E_O) and the ordinary operational pairing, then

P_PDT(O|I,R) = Tr[E_O Lambda_R(rho)] = P_QM(O|I,R).

This is an identity. Therefore a scalar resource annotation, bookkeeping variable, or alternative interpretation of R cannot by itself generate a same-input probability difference.

## Decisive falsification
The candidate route 'retain the same state, same physical resource-window channel, same effect, and same probability pairing, but obtain a different PDT probability solely from PDT resource bookkeeping' is FALSIFIED.

Any genuine deviation must specify at least one changed operational ingredient: (i) a PDT-native state/effect space; (ii) a different physical map Lambda_R generated by the same externally declared resource budget; (iii) a different probability pairing; or (iv) contextual dependence on an operationally specified record. Such a change must then be compared against QM using identical externally controlled preparation and resource conditions; it cannot be described as identical operational input if the actual channel/effect has silently changed.

## Resource-window corollary
Resource limitation can create a testable difference only if PDT derives a resource-to-dynamics/effects map R -> Lambda_R^PDT (or R -> E_R^PDT) that differs quantitatively from the quantum prediction under the same externally declared R. The experimentally meaningful target is therefore

Tr[E_O Lambda_R^PDT(rho)] != Tr[E_O Lambda_R^QM(rho)],

with rho, external controls, R, and readout protocol held fixed. This is not yet a PDT prediction; the required PDT-native map remains OPEN.

## Relation to Cycle 153
Cycle 153 showed that in n>=3, ordinary Hilbert projectors plus normalized noncontextual orthogonal additivity already force Born/trace form (Gleason; IMPORTED/KNOWN). Cycle 154 is independent of dimension: once the full operational triple and pairing are identical, equality is tautological. Thus target (3) cannot be satisfied by bookkeeping alone in n=1..12 or higher dimensions.

## Prior-art boundary
Quantum channels, operational resource theories, and discrimination-based resource comparisons are established prior art. The closure identity is not claimed as PDT novelty. Relevant prior work includes operational resource theories of channels and general resource theories characterized through discrimination tasks.

## Status ledger

## Consequence
The strongest next attack on target (3) must construct or falsify a PDT-native resource-to-physical-map law. Candidate laws must be independently motivated, positivity/normalization preserving, compositionally consistent, stress-tested, and checked against known quantum-channel/resource-theory results before any experimental claim.
