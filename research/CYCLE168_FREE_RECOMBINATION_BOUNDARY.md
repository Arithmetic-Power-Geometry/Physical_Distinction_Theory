This cycle proves the exact boundary rather than preserving an overbroad claim.

## Hypotheses: Free Joint Recombination (FJR)
Let finite local operational quotients be Q_A and Q_B. Assume:
1. joint carrier is the Cartesian product Q_A x Q_B;
2. both coordinate projections are available;
3. simultaneous pairing of the two local records is available;
4. every deterministic function f: Q_A x Q_B -> Y to a finite output alphabet is admissible postprocessing;
5. such postprocessing does not consume an undeclared physical resource.

## Theorem 168A — finite-classical witness closure
Under FJR, the composite deterministic witness set is exactly the set of all finite-valued functions on Q_A x Q_B.

Proof. By hypothesis 3 the paired record (q_A,q_B) is jointly available. Hypothesis 4 admits every deterministic map of that pair. Therefore every finite-valued composite witness is available. Conversely each admitted witness is, by definition, a function on Q_A x Q_B. QED.

For binary factors this includes XOR/parity, AND, equality, Hamming-weight predicates and every Boolean relation. Hence no extra primitive parity witness can distinguish two FJR models that agree on the paired local record.

## Corollary 168B — n-factor exact stress
For n binary factors with full local bits and FJR, the joint carrier has 2^n records and the deterministic Boolean witness family has 2^(2^n) members. The result is exact for n=1,...,12 and all finite n. No numerical approximation is required.

The sizes for n=1,...,5 are 4, 16, 256, 65536, and 2^32 Boolean witnesses; direct enumeration beyond this is unnecessary because the counting proof is exact.

## Theorem 168C — FJR does not derive itself from PDT distinction primitives
The closure theorem is conditional, not a PDT-native composition derivation. Removing any of hypotheses 1, 3, or 4 admits countermodels:
- restricted carrier: correlated subset S proper subset Q_A x Q_B;
- no joint pairing: only separately accessible records;
- restricted postprocessing: a proper function class (linear, local, bounded-depth, thermodynamically limited, etc.).

These models can preserve the same local quotients while changing the composite witness set. Therefore local distinction data alone do not imply FJR. QED.

## Resource consequence
If physical resources constrain pairing or postprocessing, then declaring arbitrary Boolean closure for free hides the resource theory inside the composition axiom. Any PDT-vs-QM prediction obtained only after imposing FJR cannot be advertised as derived from PDT unless FJR is independently justified by PDT primitives and the declared resource window.

Therefore Theorem 168A is not claimed as mathematical novelty. Its value here is an internal falsification/correction boundary for PDT-II.
