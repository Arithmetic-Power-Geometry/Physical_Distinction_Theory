# Cycle 187 — Revelation rank is submodular, but not PDT-specific

Status: **PROVED / IMPORTED-KNOWN / FALSIFIED (as PDT-specific novelty) / OPEN**

## Target attacked
The strongest surviving target after Cycle 186 was whether a resource filtration forces a non-generic constraint on revelation increments (submodularity, composition deficit, or strict bottleneck inequality).

## Setup
Let V be a finite-dimensional state/record vector space and let a finite resource set S consist of linear effects e:V→F. For A⊆S define

- E_A = span(A) ⊆ V*,
- K_A = ⋂_{e∈A} ker(e),
- Q_A = V/K_A,
- D(A)=dim Q_A = rank of the evaluation map generated by A = dim span(A).

No probability rule, norm, inner product, Hilbert structure, Born rule, or dynamics is assumed.

## Theorem 187.1 — monotonicity and unit increment
For A⊆B⊆S, D(A)≤D(B). For e∈S,

0 ≤ D(A∪{e})−D(A) ≤ 1.

Proof: D is the dimension of a span. Adding one vector either leaves the span unchanged or raises its dimension by one.

## Theorem 187.2 — submodular revelation / diminishing returns
For all A,B⊆S,

D(A)+D(B) ≥ D(A∪B)+D(A∩B).

Equivalently, if A⊆B and e∉B,

D(A∪{e})−D(A) ≥ D(B∪{e})−D(B).

Proof: write U=span(A), W=span(B). The subspace identity

dim U + dim W = dim(U+W)+dim(U∩W)

holds. Since span(A∪B)=U+W and span(A∩B)⊆U∩W,

D(A)+D(B)=D(A∪B)+dim(U∩W) ≥ D(A∪B)+D(A∩B).

The diminishing-returns form follows from the same rank law (or by checking whether e lies in the relevant spans).

## Equality and strictness
Equality holds iff span(A∩B)=span(A)∩span(B). Strict inequality is possible because common linear consequences need not be represented by effects literally common to A and B.

Small strict witness in V*=F^2:
A={e1,e2}, B={e1+e2,e2}. Then D(A)=D(B)=2, D(A∪B)=2, A∩B={e2} so D(A∩B)=1. Hence 4>3.

## Exact dimension stress test n=1,…,12
For every ambient dimension n=1,…,12, the claims above are identities of finite-dimensional linear algebra, so exhaustive numerical sampling is not required for validity. Degenerate cases are covered:

- A=∅ gives D=0;
- repeated/proportional effects give zero marginal revelation;
- a spanning resource set saturates at D=n;
- zero effects never increase D;
- the result is independent of the choice of norm;
- invertible/reversible changes of coordinates preserve all ranks;
- over product-generated effect spaces, Cycle 185's quotient tensor law remains compatible with these rank identities.

The same proof applies in every finite dimension above 12.

## Adversarial search / attempted stronger statements
1. **Strict diminishing returns** is false. Small witness: choose e linearly independent of span(B); then both marginal increments are 1. Alternatively choose e∈span(A); both are 0.
2. **Every newly added resource reveals one new dimension** is false. Small witness: A={e1}, add 2e1; increment 0.
3. **A positive universal lower bound on marginal revelation** is false for the same witness.
4. **A PDT-specific submodularity claim** is rejected: D is exactly a representable/vector-matroid rank function.
5. **Modularity on literal resource sets** is false; the strict witness above gives the smallest transparent mechanism. Modularity is restored on the lattice of effect subspaces U,W, where dim U+dim W=dim(U+W)+dim(U∩W).

## Prior-art boundary
The independent subsets of vectors/rows of a matrix form a matroid; their rank is the dimension/cardinality of a maximal independent subset. Thus D(A)=dim span(A) is the standard representable/vector-matroid rank function. Submodularity/diminishing returns is therefore established mathematical structure, not a PDT-native breakthrough. The subspace-dimension identity is likewise standard modular-lattice linear algebra.

## Consequence for PDT-II
Cycle 186's exact revelation accounting remains useful, and this cycle adds a rigorous diminishing-returns theorem for finite linear effect resources. But **submodularity cannot be promoted as PDT novelty or as an experimentally distinctive inequality**: any finite linear operational theory with the same resource representation inherits it.

A genuinely PDT-specific next step must use additional independently motivated physical structure and produce a restriction stronger than representable-matroid rank. Candidate directions to falsify next: resource-cost-weighted revelation, noncommuting/sequential accessibility, environment-record constraints, or composition deficits that cannot be reduced to ordinary rank identities.
