# Cycle 188 — Sequential noncommuting revelation is order dependent

## Status

- **PROVED:** finite-dimensional sequential revelation rank can depend on intervention order.
- **FALSIFIED:** the Cycle-186 path-independent revelation accounting law does **not** extend from nested static resource windows to arbitrary sequential/noncommuting dynamics.
- **IMPORTED/KNOWN:** the mechanism is ordinary switched-system observability/rank growth; switching-sequence dependence is established control-theory territory.
- **OPEN:** whether PDT supplies additional physical restrictions that force an order-independent invariant, or a genuinely PDT-native quantitative order-defect law.
- **BREAKTHROUGH CANDIDATE:** NO.

## Setup

Let the microscopic state space be a finite-dimensional real vector space V and let a currently accessible effect be a row functional e. For an ordered intervention/dynamics word W=(T_1,...,T_k), define the sequentially revealed effect space

E(W) = span{ e, e T_1, e T_1 T_2, ..., e T_1 ... T_k }

and its revelation dimension D(W)=dim E(W). This is the natural dynamic analogue of the static resource-window rank used in Cycles 184–187.

The question is whether D is invariant under reordering the same reversible interventions.

## Small decisive counterexample

Dimension 3 is sufficient, using only reversible permutation matrices and a single pure coordinate effect.

Take

e = (1,0,0),

A = [[1,0,0],[0,0,1],[0,1,0]]  (swap coordinates 2 and 3),

B = [[0,1,0],[1,0,0],[0,0,1]]  (swap coordinates 1 and 2).

Both A and B are orthogonal permutation matrices, hence reversible under every permutation-invariant norm.

For order A then B:

- e = (1,0,0)
- eA = (1,0,0)
- eAB = (0,1,0)

so D(A,B)=2.

For order B then A:

- e = (1,0,0)
- eB = (0,1,0)
- eBA = (0,0,1)

so D(B,A)=3.

Therefore

D(A,B) != D(B,A).

The same initial effect, same two reversible interventions, same microscopic dimension, and same intervention multiset reveal different dimensions solely because of temporal order.

## Theorem — no unrestricted dynamic path independence

For sequential revelation defined by prefix-pulled effects, arbitrary reversible noncommuting dynamics do not admit a general order-independent dimension law depending only on the unordered intervention set.

### Proof

The explicit 3-dimensional reversible construction above has the same unordered set {A,B} but D(A,B)=2 and D(B,A)=3. Any proposed universal invariant equating these two ranks is therefore false. QED.

## Minimality within permutation dynamics

For n=1 no nontrivial order effect exists. For n=2, permutation dynamics form S_2, which is abelian, so the above noncommuting permutation mechanism is unavailable. The first permutation dimension admitting noncommuting reversible interventions is n=3, and the displayed S_3 witness already produces a one-unit revelation defect. Thus n=3 is the smallest witness within the pure-coordinate/permutation subclass.

## Dimension stress test

The n=3 witness embeds block-diagonally into every n>=3 by fixing coordinates 4,...,n. Hence the falsification holds exactly for every n=3,...,12 and every finite n>12. n=1 is degenerate; the permutation-only n=2 subclass has no noncommuting pair.

No numerical approximation is required for this result.

## Edge cases and surviving laws

1. **Static nested windows:** Cycle 186 remains valid. For E_R subset E_R', the short exact sequence and telescoping dimension accounting are unchanged.
2. **Commuting dynamics:** order dependence from matrix multiplication disappears when all transformations commute, although prefix spans can still depend on which prefixes are sampled unless the protocol is specified symmetrically.
3. **Full final orbit window:** if the resource definition includes the span of all effects generated by the entire transformation semigroup/group rather than only the realized temporal prefixes, the resulting orbit span is order-independent by construction. This is a different resource model and can be substantially larger than what a finite realized trajectory reveals.
4. **Reversible groups:** the counterexample already lies in the finite reversible group S_3 and uses orthogonal transformations; noninvertibility or dissipation is not needed.
5. **Norms:** because the witness uses coordinate permutations, it is an isometry for every permutation-invariant norm (including l_p norms). The rank conclusion itself is norm-independent.
6. **Controlled environment records:** retaining a classical record of intervention order distinguishes AB from BA rather than restoring equality. Erasing the record can quotient the histories together only by imposing an additional coarse-graining.
7. **Markovianity:** the witness is a deterministic Markovian switched linear evolution. Therefore non-Markovian memory is not necessary for path dependence.

## Consequence for a proposed conservation law

The Cycle-186 conservation identity is a telescoping identity along one nested filtration. It must not be promoted to a statement that different dynamic paths with the same intervention inventory reveal the same total distinction dimension.

A legitimate dynamic quantity is instead an order defect

Delta_e(A,B) = D(B,A) - D(A,B).

For the witness above Delta_e(A,B)=1. But this quantity is presently only a diagnostic: it is not yet a PDT-native physical law, and its general bounds/operational meaning remain OPEN.

## Prior-art boundary

Switched linear-system observability already studies observability matrices/subspaces that depend on switching sequences, including cases where switching can make a whole system observable although individual subsystems are not. Therefore sequence-dependent revelation rank must be classified as **IMPORTED/KNOWN** at the mathematical-mechanism level. PDT novelty cannot rest on rediscovering this fact.

Relevant prior-art checkpoint: B. Liu, X. Shen, L. Wu, H. Su, “Observability of leader-based discrete-time multi-agent systems with switching topology,” IET Control Theory & Applications (2020), DOI 10.1049/iet-cta.2020.0202. The paper explicitly designs switching sequences/subspace sequences for observability and notes that switching can yield observability even when individual subsystems are unobservable.
