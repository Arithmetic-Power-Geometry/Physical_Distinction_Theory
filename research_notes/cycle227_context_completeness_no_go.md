# Cycle 227 — Context-completeness no-go for recursive admissibility

Status: **PROVED (abstract theorem)** / **FALSIFIED candidate selector** / **IMPORTED-KNOWN boundary** / **OPEN PDT-native replacement**

## Target attacked
PDT-II target (1), strongest survivor after Cycle 226: whether recursive contextual preservation

`Adm_{k+1}(F;R) iff F preserves every admissible k-order distinction test in every allowed context`

can itself determine the missing PDT-native composition/admissibility law.

## Exact hypotheses
Let X be a nontrivial finite distinction carrier, |X|=n>=2. Let L be the locally generated reversible maps on X×X (products of permutations of each factor). Let H be the reversible closure generated by L together with the controlled permutation

C(x,y)=(x, y+x mod n).

Let a context family be closed under identities, sequential composition, parallel composition with identities, and recursive insertion of already admitted maps. Define contextual admissibility relative to a context family K by preservation under every context in K.

## Theorem — context-family underdetermination
The recursive preservation schema does not uniquely determine admissibility unless the allowed context family is fixed by an independent physical principle.

### Proof
Take K_L to be the recursively closed family generated by L, and K_H the recursively closed family generated by H. Both satisfy the same closure schema. Since L is a proper subgroup of H for every n>=2, C belongs to K_H but not K_L. The latter follows because every map in L has second output depending only on y, whereas C has second output y+x mod n. Therefore the same recursive rule, applied to two internally coherent recursively closed context families, yields different admissibility sets. The rule is consequently a closure operator conditional on a seed/context class, not a selector of that class. QED.

At n=1 the construction collapses, as required.

## Dimension stress
The witness is exact for every n=2,...,12 and extends algebraically to every finite n>=2. No numerical approximation is involved. The invariant excluding C from L is dependency structure of the second output, so the argument is norm-independent.

## Adversarial checks
* Degenerate n=1: no separation; correctly excluded.
* Different norms: irrelevant because the witness is algebraic/reachability-based.
* Ancillas: both families can be recursively tensor-extended; the separation remains on the embedded two-factor subsystem.
* Reversible groups: the witness uses permutations only, so no Hilbert-space or complex-field structure is assumed.
* Alternative composition: this theorem does not claim all composition rules have this form; it proves non-uniqueness of the recursive-preservation schema by exhibiting two valid completions.
* Same-input prediction: choosing K_L versus K_H changes the operational architecture, so any probability difference obtained solely from that choice is NOT a valid same-input PDT-vs-QM prediction.
