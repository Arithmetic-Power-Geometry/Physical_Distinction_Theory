# Cycle 223 — Contextual-composition no-go

## Target attacked
PDT-II target (1): derive a PDT-native composition law from structured resources plus controller/coupling architecture, without merely defining the operational theory.

## Candidate principle tested
**Context-free reachable-closure principle.** Given local admissible operation families A_X,A_Y, a structured resource r, controller K, and a declared set C of allowed couplings, define the composite admissible algebra as the closure generated by A_X x id, id x A_Y, C, composition, convex mixing (where applicable), and discarding. Candidate claim: this data is sufficient independently of how controls are embedded into a larger environment/reference system.

## Result
**FALSIFIED.** Reachability is not context-free in general. The same nominal subsystem operations and the same listed subsystem coupling can have different admissibility when embedded into different controlled environments/reference frames, because admissibility can depend on whether an operation remains allowed after extension by an identity/reference system (complete freeness / complete resource-nongeneration is strictly stronger than subsystem preservation in general resource-theoretic formulations).

### Exact finite obstruction
Let the subsystem state set be X={0,1}. Declare the local map f:X->X, f(x)=0, admissible when tested only on X because it preserves the chosen local free set F_X={0}. Now form an extended system X x E with E={0,1} and choose a correlated free set

F_XE = {(0,0),(1,1)}.

The nominal extension f x id_E sends (1,1) to (0,1), which is not in F_XE. Hence subsystem freeness/preservation does not imply complete freeness under extension. A composition prescription that knows only the subsystem action of f cannot decide admissibility on X:E without the extension rule / environmental free structure.

The construction embeds into every n>=2 by adjoining unused labels; n=1 is degenerate. Thus increasing dimension does not remove the obstruction.

## Strengthened surviving statement
A defensible PDT composition object must be extension-stable. At minimum the input cannot merely be `(r,K,C,A_X,A_Y)` at one system size; it must specify or derive a **functorial family** of admissibility sets across ancillary/reference extensions, with compatibility under identity extension, composition and discarding. Symbolically, PDT needs something like

A_R(A->B) together with an independently physical rule ensuring which `id_E tensor Phi` remain admissible for every allowed environment/reference E.

Simply imposing complete freeness is not yet PDT novelty: it is established resource-theory structure. The open PDT-native obligation is to derive the relevant extension principle from physical distinction constraints rather than import it.

## Prior-art boundary
Quantum resource theories explicitly distinguish resource-nongenerating operations from *completely* resource-nongenerating/free operations, and tensor-product-compatible resource theories require stability when a free operation acts on one part of a larger system. Choi-defined resource theories likewise characterize when free operations coincide with completely resource-nongenerating operations. Therefore the generic extension-stability issue is **IMPORTED/KNOWN**, not a PDT breakthrough.

Relevant literature checked in this cycle:
- Chitambar & Gour, *Quantum resource theories*, Rev. Mod. Phys. 91, 025001 (2019).
- Zanoni & Scandolo, *Choi-defined resource theories*, Phys. Rev. A 111, 062407 (2025).
- Liu & Winter, *Resource theories of quantum channels and the universal role of resource erasure* (2019), emphasizing closure under tensor product/composition for channel resources.

## Consequences for remaining PDT-II targets
1. **Composition:** context-free reachable closure is falsified; extension-stable admissibility remains OPEN.
2. **n=3:** no non-circular derivation follows from this route.
3. **Same-input PDT vs QM:** changing ancillary/reference admissibility is part of the operational input. A claimed deviation is not same-input unless both theories are compared with the same declared environment/reference/control resources.
4. **Resource revelation:** scalar/vector resource accounting remains insufficient unless extension behavior is fixed.
5. **Experimental inequalities:** any inequality depending on restricted controls must state ancillary/reference permissions explicitly.
6. **Gravity/capacity:** no derivation attempted; current premises do not justify one.
